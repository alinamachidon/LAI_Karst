# LAI Karst Forest Remote-Sensing Analysis

This repository contains the field and satellite-derived data, analysis scripts, and spatial-extraction workflow used in the manuscript *Evaluating Seasonal Fidelity and Cross-Site Structural Discrimination of Sentinel-2 LAI Products in Karst Forests*.

## Contents

### Data

- `LAI_data.xlsx`
  - `Sites`: site metadata
  - `Field_LAI`: field effective LAI matrix
  - one sheet for each evaluated remote-sensing variable/product: `NDVI`, `NDWI`, `SAVI`, `OSAVI`, `EVI`, `NDRE`, `SNAP`, and `Copernicus`
  - `All_Data_Long`: analysis-ready table with one row per site × campaign

- `data/`
  - `LAI2021_PPCS.shp`, `.shx`, `.dbf`, `.prj`: georeferenced field-site points used for raster extraction
  - `point_metadata.csv`: field-site identifiers and coordinates

### Analysis scripts

- `linear_regression.py`  
  Pooled linear regressions and within-site Pearson correlations between field effective LAI and each remote-sensing variable.

- `cross_site_analysis.py`  
  Same-date cross-site Spearman correlations and percentage range retention for the SNAP and Copernicus LAI products.

- `random_forest.py`  
  Exploratory univariate Random Forest models reporting apparent full-sample fit.

- `random_forest_loso_cv.py`  
  Leave-one-site-out cross-validation of the Random Forest models. In each fold, all observations from one field site are withheld and the model is trained on the remaining sites.

- `site_center_pixel_extraction.py`  
  Extracts the raster pixel containing each georeferenced field-site coordinate. The script reprojects site points to the raster CRS, samples the corresponding pixel, records raster row/column information, and exports the extracted values in long and wide formats.

- `results/`  
  Analysis outputs generated by the scripts.

- `requirements.txt`  
  Python dependencies required to run the analyses.

## Reproducing the analyses

Python 3.10 or later is recommended.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python random_forest.py --workbook LAI_data.xlsx --outdir results
python random_forest_loso_cv.py
python linear_regression.py --workbook LAI_data.xlsx --outdir results
python cross_site_analysis.py --workbook LAI_data.xlsx --outdir results
```

The raster-extraction script expects the field-site shapefile and `point_metadata.csv` together with the relevant GeoTIFF rasters. Paths and the raster scale factor can be configured in the user-settings section at the beginning of `site_center_pixel_extraction.py`.

## Interpretation notes

- The pooled analyses combine repeated observations from the same field sites and are therefore interpreted descriptively rather than as analyses of 42 statistically independent observations.
- Random Forest full-sample metrics describe apparent in-sample fit only. Site-level transferability is evaluated separately using leave-one-site-out cross-validation.
- NDWI is stored using the Green−NIR formulation. The linear-regression script reports raw coefficients, while the cross-site analysis also reports direction-oriented Spearman coefficients with NDWI multiplied by −1.
- Same-date cross-site analyses require at least four matched sites.
- Percentage range retention is calculated only for SNAP and Copernicus because these products are expressed in nominal LAI units and can be compared directly with the field effective LAI range.
- Field effective LAI values represent the mean of five fixed below-canopy LAI-2200 measurements within each 10 × 10 m site. Raster matching uses the single pixel containing the corresponding georeferenced site coordinate; no plot-area or neighborhood averaging is applied in the primary extraction workflow.
