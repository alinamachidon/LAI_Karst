# LAI remote-sensing analysis transparency package

This package consolidates the field and satellite-derived data used in the manuscript into a single workbook and provides three focused scripts that reproduce the reported analyses.

## Contents

- `LAI_data.xlsx`
  - `Sites`: site metadata
  - `Field_LAI`: field effective LAI matrix
  - one sheet for each method: `NDVI`, `NDWI`, `SAVI`, `OSAVI`, `EVI`, `NDRE`, `SNAP`, and `Copernicus`
  - `All_Data_Long`: canonical analysis-ready sheet with one row per site × campaign
- `01_random_forest.py`: apparent full-sample Random Forest fit used in the manuscript
- `02_linear_regression.py`: pooled linear regressions and within-site Pearson correlations
- `03_cross_site_analysis.py`: same-date cross-site Spearman correlations and percentage range retention
- `results/`: outputs generated by running the three scripts
- `requirements.txt`: Python dependencies

## Reproducing the analyses

Python 3.10 or later is recommended.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python random_forest.py --workbook LAI_data.xlsx --outdir results
python linear_regression.py --workbook LAI_data.xlsx --outdir results
python cross_site_analysis.py --workbook LAI_data.xlsx --outdir results
```

## Interpretation notes

- Random Forest metrics are full-sample fit: the same observations are used for fitting and evaluation.
- NDWI is stored using the Green−NIR formulation. The linear-regression script reports raw coefficients. The cross-site script reports both raw and direction-oriented Spearman coefficients, with NDWI multiplied by −1 for the oriented result.
- Same-date analyses require at least four matched sites. 
- Percentage range retention is calculated only for SNAP and Copernicus because they are expressed in nominal LAI units and can be compared directly with the field LAI range.
